# sarqt

> Лишняя еда не идёт в мусор — она идёт соседу.

sarqt — сервис, где сосед отдаёт лишнюю свежую еду, а сосед рядом её забирает. Бесплатно, без посредников, без денег.

**Сайт:** [sarqt.kz](https://sarqt.kz)

## Что это

У кого-то осталась лишняя свежая еда — кафе не распродало к концу дня, после тоя остался бешбармак, дома приготовили слишком много. Хозяин публикует короткий оффер с фото; сосед в пешей доступности видит его в ленте и звонит забрать.

- Бесплатно для всех — ни комиссий, ни платных функций.
- Ноль денежного потока через платформу — еда передаётся напрямую.
- Открытая хроника — каждая завершённая передача видна публично: район и что именно, без имён и контактов.
- Интерфейс на трёх языках — русский, казахский, английский.

## Как это работает

1. Хозяин лишней еды публикует оффер с фото и указывает, до какого часа её можно забрать.
2. Сосед поблизости видит оффер в ленте и звонит хозяину напрямую.
3. Договариваются, сосед забирает. Завершённая передача попадает в открытую хронику.

## Архитектура

Статическое веб-приложение без сборки:

- **Фронтенд** — ванильный HTML/CSS/JS, ES-модули, hash-роутинг. Хостинг — GitHub Pages.
- **Бэкенд** — Supabase (Postgres + Auth + Storage). Фронтенд обращается к Supabase напрямую; граница безопасности — RLS-политики Postgres.
- **Без build-step** — ноль сборки, ноль рантайм-зависимостей от CDN (`supabase-js` вендорится в `js/vendor/`).

## Структура репозитория

```
index.html              приложение (разметка + CSS)
js/                     ES-модули: роутер, вьюхи, слой Supabase
js/i18n.js              движок i18n — t() с фолбэком на ru
js/messages.js          словарь UI-строк (ru / kk / en)
js/vendor/              вендоренный supabase-js
supabase/migrations/    SQL-миграции схемы и RLS
tests/                  тесты Vitest
manifest.json  sw.js    PWA-манифест и service worker
favicon.svg             иконка
404.html  oferta.html   статические страницы
```

## Локальная разработка

```
npm install      # зависимости (Vitest)
npm test         # запустить тесты
npx serve        # локальный сервер → http://localhost:3000
```

Приложению нужен HTTP-сервер — с `file://` не зарегистрируется service worker.
